# Images Directory / 图片目录

This directory contains all images used in notes, organized by category.

本目录包含笔记中使用的所有图片，按类别组织。

## Directory Structure / 目录结构

- `screenshots/` - Screen captures and application screenshots / 屏幕截图和应用程序截图
- `diagrams/` - Technical diagrams, flowcharts, and architecture diagrams / 技术图表、流程图和架构图
- `icons/` - Icons and small images / 图标和小图片
- `misc/` - Miscellaneous images that don't fit other categories / 其他不适合其他类别的图片

## Usage / 使用方法

Upload your images to the appropriate directory and reference them in your markdown notes using the raw GitHub URL:

将图片上传到相应的目录，并在markdown笔记中使用GitHub原始URL引用：

```markdown
![Description](https://raw.githubusercontent.com/Shallow-W/img_repo/main/images/category/image-name.png)
```

## Naming Convention / 命名规范

- Use descriptive names / 使用描述性名称
- Use lowercase with hyphens / 使用小写字母和连字符
- Example: `user-login-flow.png`, `database-schema.jpg`
- 示例：`user-login-flow.png`, `database-schema.jpg`
